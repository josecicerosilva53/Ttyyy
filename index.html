Configurar o Firebase

  1. No console do Firebase, crie um projeto e registre um app da Web. Copie o objeto firebaseConfig do seu projeto e substitua o bloco com esse nome no código deste HTML.
  2. Em Authentication → Sign-in method, ative E-mail/senha. Na aba Users, crie uma conta para Cícero e outra para Douglas e copie o UID de cada conta.
  3. Crie um banco Cloud Firestore em modo de produção. Na aba Rules, cole e publique as regras abaixo em um banco dedicado a esta carteira.
  4. Na aba Data, crie a coleção membros com um documento para cada pessoa. Use o UID como ID do documento e adicione o campo nome, do tipo string, com o nome que deve aparecer no painel. Para trocar um nome, edite esse campo.
  5. Hospede o HTML em HTTPS. Para abrir pela página inicial do site, salve como index.html. Abra o mesmo endereço nos dois celulares e entre com a conta de cada pessoa.
Regras do Firestore para copiar 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function membro() {
      return request.auth != null
        && exists(/databases/$(database)/documents/membros/$(request.auth.uid));
    }
    match /membros/{uid} {
      allow get: if request.auth != null
        && (request.auth.uid == uid || membro());
      allow list: if membro();
    }
    match /aportes/{id} {
      allow read: if membro();
      allow create: if membro()
        && request.resource.data.keys().hasAll(['autor', 'centavos', 'data'])
        && request.resource.data.keys().hasOnly(['autor', 'centavos', 'data'])
        && request.resource.data.autor == request.auth.uid
        && request.resource.data.centavos is int
        && request.resource.data.centavos > 0
        && request.resource.data.centavos <= 100000000
        && request.resource.data.data is string
        && request.resource.data.data.matches('[0-9]{4}-(0[1-9]|1[0-2])-(0[1-9]|[12][0-9]|3[01])');
    }
  }
}
